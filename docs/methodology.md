# 研究方法与计算时点

本项目实现“跨频段回撤修复”这一待检验假设：高频修复信号，是否在此前上涨、近期适度回调的低频背景下更有预测力？因子设计是研究起点，不是已经得到验证的交易结论。

## 时间轴与信息集合

所有偏移按共同交易日历计算，不按某只股票剩余的有效观测压缩时间。默认在交易日 $t$ 收盘后计算信号。

| 时段 | 用途 |
| --- | --- |
| $t-25$ 收盘至 $t-5$ 收盘 | 20 日此前趋势 |
| $t-5$ 收盘至 $t-1$ 收盘 | 4 日近期回调 |
| $t-20$ 至 $t-1$ 的日收益 | 日频正常波动率基准 |
| $t-20$ 至 $t-1$ 的尾盘窗口 | 尾盘波动率与成交量基准 |
| $t$ 的 14:00–15:00 | 今日尾盘修复与成交量 |
| $t+1$ 开盘 | 最早入场 |
| $t+5$ 收盘 | 默认五日持有期的离场 |

默认收益标签为：

$$
y_{i,t}^{(5)}=\frac{C_{i,t+5}}{O_{i,t+1}}-1.
$$

这覆盖 $t+1$ 至 $t+5$ 的五个完整交易时段。因子不使用 $t+1$ 及之后的信息；标签、交易结果与因子分别计算。样本末端没有完整未来窗口的标签保持缺失。

## 精确公式

令 $r_{i,s}=C_{i,s}/C_{i,s-1}-1$，$\sigma_{i,t}$ 为 $r_{i,t-20},\ldots,r_{i,t-1}$ 的样本标准差（`ddof=1`）。定义：

$$
M_{i,t}=\frac{C_{i,t-5}/C_{i,t-25}-1}{\sigma_{i,t}\sqrt{20}},
\qquad
D_{i,t}=\frac{\max\{-(C_{i,t-1}/C_{i,t-5}-1),0\}}{\sigma_{i,t}\sqrt{4}}.
$$

默认尾盘收益 $h_{i,t}$ 为 14:59 这一分钟的收盘价，除以 14:00 这一分钟的开盘价，再减一。分钟条以**开始时间**标记；14:59 条覆盖至 15:00。尾盘成交量 $v_{i,t}^{tail}$ 是这 60 根一分钟条的成交量之和。

$$
H_{i,t}=\frac{h_{i,t}}{\operatorname{std}(h_{i,t-20},\ldots,h_{i,t-1})},
\qquad
Q_{i,t}=\frac{v_{i,t}^{tail}}{\operatorname{mean}(v_{i,t-20}^{tail},\ldots,v_{i,t-1}^{tail})}.
$$

最终得分为：

$$
F_{i,t}=[M_{i,t}]_+\cdot g(D_{i,t})\cdot[H_{i,t}]_+\cdot\min(Q_{i,t},2),
\qquad
g(D)=De^{-D^2/2}.
$$

其中 $g'(D)=e^{-D^2/2}(1-D^2)$，故在非负域上 $D=1$ 为最大值。$D=0$ 时为零；$D=3$ 时已经接近零。该形状明确表达“中等程度回调”的先验，而不是优先选择跌幅最大的股票。

乘法使三个方向条件共同发挥作用：趋势不为正、没有回调或尾盘没有上涨时，得分为零。成交量封顶限制异常放量的影响；成交量本身不能识别交易者身份。

## 有效样本与缺失值

默认至少需要 26 个日收盘观测，且尾盘窗口及之前 20 个交易日的尾盘基准完整。所有历史窗口要求完整数据；不跳过缺失交易日重新拼接一个“20 日”窗口。

| 情况 | 处理 |
| --- | --- |
| 数据充分，但趋势、回调或修复的方向条件不满足 | 有效因子，得分为零 |
| 历史不足、缺失分钟、波动率为零或过小、成交量基准为零 | 因子缺失，记录原因 |
| 当日 `tradable=False` | 不作为有效信号；停牌价格不用于制造有效历史收益 |
| 某股票缺少一个交易日 | 保留共同日历的空档，不把之后一天当作缺失日 |

零分样本保留在统计截面内，防止只分析已通过门槛的股票。组合实际买入要求正分。控制变量缺失影响对应回归，不能据此把缺失因子改成零。

## 对照信号与增量预测力

项目提供以下对照：

| 名称 | 定义 |
| --- | --- |
| `control_momentum` | 原始此前趋势 $C_{t-5}/C_{t-25}-1$ |
| `control_reversal` | 原始近期收益的相反数 $-(C_{t-1}/C_{t-5}-1)$ |
| `control_volume` | 今日**全日**成交量与此前 20 日全日平均成交量之比的自然对数 |
| `hf_signal` | 单独的高频修复 $[H]_+\min(Q,2)$ |

这些是初始的普通趋势、短期反转与成交量控制，没有完成全部风险暴露控制。行业、市值、换手率、历史波动率等可以作为后续研究扩展。`control_volume` 是相对股数成交量，不是使用流通股本计算的换手率。

对每个交易日，以截面内均值和总体标准差（`ddof=0`）同时标准化未来收益与四个解释变量，估计含截距的 OLS：

$$
z(y_{i,t}^{(5)})=a_t+\beta_t z(F_{i,t})+
\gamma_{1,t}z(\mathrm{momentum}_{i,t})+
\gamma_{2,t}z(\mathrm{reversal}_{i,t})+
\gamma_{3,t}z(\mathrm{volume}_{i,t})+\epsilon_{i,t}.
$$

$\beta_t$ 表示控制这些变量后，一个因子截面标准差对应多少个未来收益截面标准差。它不是百分比收益，不是因果效应，也不等于可交易的组合收益。

每次回归仅使用当日所需字段完整的样本；默认至少 10 只股票，且不少于 6 只。解释变量或收益为常数、样本不足、设计矩阵不满秩等日期会跳过，并保留状态与样本数。报告区分有效回归日和跳过日。

## IC、分位数与统计汇总

Rank IC 是每日有效截面中因子与未来收益的 Spearman 相关系数，分数并列采用平均秩。常数因子截面没有可识别的相关性，记为缺失，不伪造零 IC。

各对照信号的 IC 使用该信号自身字段可用的有效样本，逐日记录样本数与状态。可用覆盖范围可能不同，不能只比较两个平均 IC 就声称取得了配对意义上的统计改进；正式对照应进一步对齐共同股票和日期。

分位数组合使用平均秩分箱，保留相同分数的并列关系，不按股票代码随意把同分样本拆开。因而部分分组可以为空，样本数未必相同；常数截面不分组。分组收益是标签的简单均值，用于研究预测排序，不是扣费后的可执行净值。

IC 与逐日增量回归系数的时间均值，使用 Bartlett 权重的 Newey–West 标准误。默认滞后阶数为 `horizon - 1`；自定义值也不能小于这一数值。缺失日期保留其交易日位置，不把相隔多日的有效统计量当作相邻日。报告包含有效样本数、滞后阶数与 t 值，不以单个统计量判定因子有效。

默认五日标签相互重叠，HAC 是必要的初步修正，仍不能替代足够长的样本、样本外检验或多重检验控制。

## 多头回测与交易成本

组合按不重叠的五交易日批次运行。每个信号日先用全部有效股票（含零分）数量 $N_t$ 确定目标持仓数 $k_t=\lceil N_t\cdot\mathrm{top\_fraction}\rceil$，再按得分降序选至多 $k_t$ 只有效正分股票。正分不足时只持有可选的正分股票，没有正分则持有现金。入选股票等权，并列分数按股票代码确定顺序。股票在信号日选定，不利用未来收益或未来数据完整性筛选赢家。

下一交易日开盘买入，持有至第五交易日收盘卖出。实际净值逐日按持仓价格计价；它不是简单将五日收益平均分摊到每天。全部有效股票组成同口径等权基准，使用相同批次、成交时点与费用。

默认 `cost_bps=10` 表示买入和卖出**各收取 0.1%**。买入时从各等权资金槽位中同时支付费用与持仓本金；卖出费用按实际卖出金额收取。未买入的槽位留作现金，不事后重新分配资金。真实佣金、印花税、滑点与市场冲击并未分别建模，应在真实数据研究中校准并进行敏感性分析。

入场日 `tradable=False` 的股票不买入，原槽位保留现金。已持仓资产缺少日估值价格或计划离场日不可交易时，当前实现报错，要求补齐数据或使用更完整的成交模型。它不会事后删除这笔交易，让结果看起来更好。每日单一 `tradable` 标记不能同时精确表达开盘与收盘成交、涨停买不进与跌停卖不出；研究者需要提供符合其执行假设的数据或扩展执行模型。

## 研究边界与下一步

模拟数据仅验证工程流程。它采用工作日序列而非真实交易所节假日日历，没有植入未来收益优势，也不代表 A 股收益分布。

在真实市场上，需要进一步固定股票池与参数、处理公司行动及幸存者偏差、做样本外验证、检查成本与容量，并将高频单独信号、低频单独信号、加法组合与乘法组合进行同样的比较。多个窗口或参数的反复试验必须考虑选择偏差。

背景参考：[New York Fed Staff Report No. 513](https://www.newyorkfed.org/research/staff_reports/sr513.html)。它为相关市场机制提供研究背景，不证明这个具体公式具备增量信息。
